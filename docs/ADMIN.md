# Οι εντολές του εργοδότη

Όλες τρέχουν στον υπολογιστή της εγκατάστασης, από τον φάκελό της (π.χ. `/opt/ergani`):

```sh
docker compose exec stamp ergani admin <εντολή> [επιλογές]
```

(Η μόνη εξαίρεση: το νέο παράρτημα, παρακάτω.)

> ⛔⛔ **Δεν υπάρχει εντολή που χτυπά κάρτα.** Ο εργοδότης ορίζει ποιος χτυπά· μόνο ο ίδιος ο εργαζόμενος χτυπά, με
> τον δικό του κωδικό, στη σελίδα της υποδοχής ([RULES.md](RULES.md), κανόνας 1).

## Το προσωπικό

| εντολή | τι κάνει |
|---|---|
| `add --afm … --surname … --first-name … [--display «Όνομα»]` | νέος εργαζόμενος· τυπώνει τον **προσωρινό κωδικό** για να του τον δώσετε αυτοπροσώπως |
| `add … --exempt «οδοντίατρος»` | πρόσωπο που **δεν** χτυπά, με τον λόγο γραμμένο |
| `list` | ποιοι χτυπούν, ποιοι εξαιρούνται και γιατί, ποιοι δεν έχουν διαλέξει ακόμη κωδικό |
| `pin --afm …` | νέος προσωρινός κωδικός (ξεχασμένος κωδικός)· ο εργαζόμενος διαλέγει ξανά δικό του |
| `unlock --afm …` | ξεκλείδωμα μετά από 5 λάθος κωδικούς (κλειδώνει για 10 λεπτά) |
| `rename --afm … [--surname …] [--first-name …] [--display …]` | διόρθωση ονόματος· οι κάρτες που στάλθηκαν κρατούν το όνομα με το οποίο στάλθηκαν |
| `exempt --afm … --reason …` · `include --afm …` | εξαίρεση από την κάρτα, ή επιστροφή |
| `deactivate --afm …` · `reactivate --afm …` | αποχώρηση (μένει στο αρχείο, φεύγει από τη σελίδα), ή επιστροφή |

Ο ΑΦΜ ενός εργαζόμενου δεν αλλάζει ποτέ: λάθος ΑΦΜ σημαίνει άλλο πρόσωπο — `deactivate` και νέο `add`.

## Οι συσκευές

| εντολή | τι κάνει |
|---|---|
| `enroll [--branch N] --label «Υποδοχή»` | σύνδεσμος μίας χρήσης (30 λεπτά) για τον υπολογιστή υποδοχής εκείνου του παραρτήματος |
| `devices` | οι εγγεγραμμένες συσκευές |
| `revoke-device --id N` | η συσκευή δεν βλέπει πια τη σελίδα |

## Κάθε μέρα

| εντολή | τι κάνει |
|---|---|
| `cards [--date YYYY-MM-DD]` | οι κάρτες μιας μέρας (προεπιλογή: σήμερα) και τι έγινε με την καθεμία |
| `queue` | κάρτες που χρειάζονται απόφαση, και κάρτες που στάλθηκαν αλλά η απόδειξη PDF δεν έχει έρθει |
| `decide --card N --reason 001\|002\|003` | εκπρόθεσμη αποστολή κάρτας της ουράς, με αιτία (συνήθως γίνεται στη σελίδα: «Τι κάνω;») |
| `decide --card N --covered` | η κάρτα καλύφθηκε αλλιώς (CardScanner, ή τη διορθώνει ο λογιστής) |
| `quiet --date YYYY-MM-DD --reason «28η Οκτωβρίου»` | κλειστή μέρα: καμία ειδοποίηση «δεν χτύπησε ΕΝΑΡΞΗ» (σε κανένα παράρτημα) |
| `unquiet --date YYYY-MM-DD --reason …` | ανάκληση της κλειστής μέρας (κρατιούνται και οι δύο) |

Οι αιτίες εκπρόθεσμης δήλωσης είναι του Υπουργείου: **001** ηλεκτροδότηση/τηλεπικοινωνίες · **002** συστήματα
εργοδότη · **003** σύνδεση με το ΠΣ ΕΡΓΑΝΗ. ⚠ Η αιτία **δεν** αντικαθιστά την ειδοποίηση της Επιθεώρησης Εργασίας —
αμέσως όταν αρχίζει το πρόβλημα, και ξανά όταν τελειώνει.

## Το αρχείο ενός εργαζόμενου — δικαίωμά του

Κάθε εργαζόμενος έχει δικαίωμα να δει τις δικές του καταγραφές.

```sh
docker compose exec stamp ergani admin history --afm <ΑΦΜ> [--from YYYY-MM-DD] [--to YYYY-MM-DD] --out /data/stamp/exports
```

Γράφει μια ελληνική σελίδα (εκτυπώνεται σε χαρτί ή PDF από τον browser) και ένα αρχείο λογιστικού φύλλου με τις
**δικές του** κάρτες μόνο, με τους αριθμούς πρωτοκόλλου της ΕΡΓΑΝΗ, σε έναν **νέο φάκελο μόνο γι' αυτό το αίτημα**,
και τυπώνει το όνομά του. Αντιγράψτε **μόνο αυτόν τον φάκελο**, σε φάκελο **έξω** από τον φάκελο της εγκατάστασης
(ποτέ μέσα σε αυτόν: είναι αντίγραφο κώδικα):

```sh
mkdir -p -m 700 ~/ergani-exports
docker compose cp stamp:<ο φάκελος που τύπωσε> ~/ergani-exports/
```

Δώστε τα **μόνο σε εκείνον**. Μετά σβήστε και τα δύο αντίγραφα:

```sh
rm -r ~/ergani-exports/<το όνομα του φακέλου>
docker compose exec stamp rm -r <ο φάκελος που τύπωσε>
```

Από το μηνιαίο αρχείο της ΕΡΓΑΝΗ (ό,τι κράτησε η ΕΡΓΑΝΗ, έναν μήνα πίσω) — το ίδιο: κάθε εντολή γράφει σε νέο φάκελο,
τον τυπώνει, και αντιγράφετε μόνο αυτόν (`docker compose cp archive:<φάκελος> ~/ergani-exports/`):

```sh
docker compose exec archive ergani export employee --afm <ΑΦΜ> --from 2026-08-01 --to 2026-08-31 --out /data/records/exports
docker compose exec archive ergani export compare --month 2026-08 --out /data/records/exports
```

Η σύγκριση «δηλωμένο ωράριο ↔ κινήσεις» ενός μήνα γράφεται και μόνη της κάθε μέρα στο `/data/records/exports`.

## Έλεγχοι

| εντολή | τι κάνει |
|---|---|
| `check [--branch N]` | **μόνο ανάγνωση**: ο χρήστης ΕΡΓΑΝΗ κάθε παραρτήματος, το έντυπο της κάρτας, το ωράριο |
| `push-test` | μία δοκιμαστική ειδοποίηση στο κινητό του εργοδότη |
| `add-branch --branch N` | νέο παράρτημα, μία φορά — **μόνο** με τα βήματα της επόμενης ενότητας |

## Νέο παράρτημα

Με αυτή τη σειρά, εκτός ωραρίου (στο βήμα 4 η σελίδα ξαναρχίζει):

1. Στην ΕΡΓΑΝΗ, ο περιορισμένος χρήστης του νέου παραρτήματος ([ERGANI-USER.md](ERGANI-USER.md)).
2. Στο `.env`: ο κωδικός του στο `ERGANI_BRANCHES` (π.χ. `ERGANI_BRANCHES=0,1`), οι δύο γραμμές
   `ERGANI_BRANCH_1_USERNAME=…` / `ERGANI_BRANCH_1_PASSWORD=…`, και — αφού τώρα είναι περισσότερα από ένα — ένα
   όνομα για **κάθε** παράρτημα, και για την έδρα: `STAMP_BRANCH_0_LABEL=Κέντρο`, `STAMP_BRANCH_1_LABEL=Λιμάνι`.
   Προαιρετικά, για το νέο: `STAMP_BRANCH_1_INSPECTORATE_EMAIL=…` και `STAMP_BRANCH_1_SCHEDULE=none`.
3. Το νέο παράρτημα στο αρχείο — με `run --rm`, **όχι** `exec`: το `exec` τρέχει μέσα στην υπηρεσία που ήδη τρέχει,
   η οποία δεν έχει δει ακόμη το νέο `.env`:
   ```sh
   docker compose run --rm stamp ergani admin add-branch --branch 1
   ```
4. `docker compose up -d` — οι υπηρεσίες ξαναρχίζουν με το νέο `.env`.
5. `docker compose exec stamp ergani admin check --branch 1`, και μετά ο υπολογιστής της υποδοχής του
   (`admin enroll --branch 1 --label "Υποδοχή"`, [INSTALL.md](INSTALL.md) §7).

⚠ Αν κάνετε το βήμα 4 πριν από το 3, η υπηρεσία αρνείται να ξεκινήσει (κανένα παράρτημα δεν δουλεύει) μέχρι να γίνει
το βήμα 3 και ξανά το 4: κάθε κάρτα πρέπει να στέλνεται με τον χρήστη του δικού της παραρτήματος, και το αρχείο δεν
ξέρει ακόμη το νέο.

## Το μηνιαίο αρχείο

Τρέχει μόνο του κάθε μέρα στις 03:15. Με το χέρι:

```sh
docker compose exec archive ergani pull --month 2026-09            # όλα τα παραρτήματα
docker compose exec archive ergani pull --month 2026-09 --branch 1 # ένα
docker compose logs archive                                        # τι έκανε
```

Ξαναδιάβασμα ενός μήνα δεν διπλασιάζει τίποτα· ό,τι άλλαξε στην ΕΡΓΑΝΗ προστίθεται δίπλα σε ό,τι υπήρχε.
