# Εγκατάσταση στον υπολογιστή του ιατρείου

<img src="../src/brand/odontia-mark.svg" width="20" height="20" alt=""> Φτιαγμένο από την [Odontia](https://odontia.ai)

Ένα πρόγραμμα για τον υπολογιστή της υποδοχής — **Windows, Mac ή Linux**. Το εγκαθιστάτε με διπλό κλικ, ξεκινά μόνο του
κάθε φορά που ανοίγει ο υπολογιστής, και η «οθόνη» του είναι μια σελίδα στον browser. Οι εργαζόμενοι χτυπούν κάρτα σε
αυτόν τον υπολογιστή, ή από το κινητό τους στο Wi-Fi του ιατρείου. Δεν χρειάζεται Docker, ούτε γραμμή εντολών.

> ⛔⛔ **Στο πραγματικό μητρώο, κάθε κάρτα είναι νόμιμη δήλωση του εργοδότη για συγκεκριμένο πρόσωπο.** Το πρόγραμμα
> διατίθεται δωρεάν και **χωρίς καμία εγγύηση** (άδεια EUPL-1.2)· ο εργοδότης παραμένει υπεύθυνος για τις δηλώσεις του
> στην ΕΡΓΑΝΗ. Διαβάστε τους κανόνες του: [RULES.md](RULES.md).

## Τι χρειάζεστε

- **Τον υπολογιστή της υποδοχής**, ανοιχτό όσο δουλεύει το ιατρείο: Windows 10 ή 11 (64-bit), Mac με macOS 13.5 ή
  νεότερο, ή Linux 64-bit (Ubuntu 22.04+, Debian 12+ και άλλα).
- **Για κάθε παράρτημα, έναν περιορισμένο χρήστη ΕΡΓΑΝΗ** — τον φτιάχνετε μία φορά με τους κύριους κωδικούς, που δεν
  δίνονται ποτέ στο πρόγραμμα. Τα βήματα είναι και μέσα στη ρύθμιση· αναλυτικά: [ERGANI-USER.md](ERGANI-USER.md).
- **Για τα κινητά: το Wi-Fi του ιατρείου** (με κωδικό, WPA2 ή WPA3) — **ποτέ** το Wi-Fi επισκεπτών.
- **Το CardScanner** του Υπουργείου σε ένα κινητό του ιατρείου, ως εφεδρεία για όταν η σελίδα δεν ανοίγει.

## 1. Κατεβάστε το πρόγραμμα

Από τη σελίδα **[Εκδόσεις (Releases)](../../../releases/latest)** του έργου, το αρχείο για τον υπολογιστή σας:

| Υπολογιστής | Αρχείο |
|---|---|
| Windows 10 / 11 | `karta-ergasias-<έκδοση>-windows-x64-setup.exe` |
| Mac με επεξεργαστή Apple (M1, M2, …) | `karta-ergasias-<έκδοση>-mac-arm64.zip` |
| Mac με επεξεργαστή Intel | `karta-ergasias-<έκδοση>-mac-x64.zip` |
| Linux — Ubuntu, Debian, Mint | `karta-ergasias-<έκδοση>-linux-x64.deb` |
| Linux — άλλες διανομές | `karta-ergasias-<έκδοση>-linux-x64.tar.gz` |

(Στο Mac: μενού  → «Πληροφορίες για αυτό το Mac» → «Τσιπ: Apple …» ή «Επεξεργαστής: Intel …».)

ⓘ **Γιατί ο υπολογιστής θα «προειδοποιήσει»:** το πρόγραμμα δεν φέρει πληρωμένο πιστοποιητικό υπογραφής (Microsoft ή
Apple). Γι' αυτό, **μόνο την πρώτη φορά**, Windows και Mac ζητούν ένα-δύο κλικ παραπάνω — φαίνονται παρακάτω. Οι
ενημερώσεις αργότερα δεν ξαναζητούν τίποτα: είναι υπογεγραμμένες με το κλειδί του έργου, και το πρόγραμμα αρνείται
οτιδήποτε άλλο.

## 2. Εγκατάσταση

### Windows

1. Διπλό κλικ στο `…-windows-x64-setup.exe`.
2. Αν εμφανιστεί **«Τα Windows προστάτευσαν τον υπολογιστή σας»**: πατήστε **«Περισσότερες πληροφορίες»** και μετά
   **«Εκτέλεση ούτως ή άλλως»**.
3. **«Θέλετε να επιτρέψετε σε αυτή την εφαρμογή να κάνει αλλαγές;»** → **Ναι**. (Μία φορά: εγκαθιστά το πρόγραμμα για
   τον υπολογιστή, και ανοίγει τη θύρα 8880 μόνο στα **ιδιωτικά** δίκτυα, για να το βρίσκουν τα κινητά.)
4. **Επόμενο** … **Εγκατάσταση** … **Τέλος**, με επιλεγμένο «Άνοιγμα της Κάρτας Εργασίας»: ανοίγει ο browser στη ρύθμιση.

Για τα κινητά, το δίκτυο του ιατρείου πρέπει να είναι **Ιδιωτικό** στα Windows: Ρυθμίσεις → Δίκτυο και Internet → Wi-Fi
(ή Ethernet) → το δίκτυό σας → **Τύπος προφίλ δικτύου: Ιδιωτικό**.

### Mac

1. Διπλό κλικ στο `….zip`: εμφανίζεται η **«Κάρτα Εργασίας»**. **Σύρετέ την στον φάκελο Εφαρμογές** (Applications) —
   όχι να την ανοίξετε από τις Λήψεις.
2. Ανοίξτε την από τις Εφαρμογές. Το Mac λέει ότι δεν μπορεί να επαληθεύσει τον δημιουργό: πατήστε **«Τέλος»**.
3. **Ρυθμίσεις συστήματος → Απόρρητο και ασφάλεια** → κάτω-κάτω, στο «Η "Κάρτα Εργασίας" μπλοκαρίστηκε…» πατήστε
   **«Άνοιγμα ούτως ή άλλως»**, δώστε τον κωδικό του Mac, και **«Άνοιγμα»**.
4. Ανοίγει ο browser στη ρύθμιση. Από εδώ και πέρα ξεκινά μόνο του σε κάθε σύνδεση στο Mac.

Αν το τείχος προστασίας του Mac είναι ενεργό και ρωτήσει για εισερχόμενες συνδέσεις του «node»: **Να επιτρέπεται**
(αλλιώς τα κινητά δεν βρίσκουν τη σελίδα).

### Linux

- **Ubuntu, Debian, Mint:** διπλό κλικ στο `.deb` → «Εγκατάσταση» (ή `sudo apt install ./karta-ergasias-….deb`). Μετά
  ανοίξτε την **«Κάρτα Εργασίας»** από τις εφαρμογές.
- **Άλλες διανομές:** αποσυμπιέστε το `.tar.gz` και τρέξτε `sh install.sh` (χωρίς δικαιώματα διαχειριστή· μόνο για τον
  χρήστη σας). Αφαίρεση: `sh uninstall.sh`.

## 3. Η πρώτη ρύθμιση — στον browser, στα ελληνικά

Η σελίδα ρύθμισης ανοίγει μόνη της (αλλιώς: <http://127.0.0.1:8881>). Συμπληρώνετε:

1. **Τους όρους**: «Το χρησιμοποιώ με δική μου ευθύνη· ως εργοδότης παραμένω υπεύθυνος για τις δηλώσεις μου στην ΕΡΓΑΝΗ».
2. **Τον εργοδότη**: την επωνυμία και το ΑΦΜ.
3. **Κάθε παράρτημα**: τον αριθμό του (η έδρα είναι το `0`) και τον **περιορισμένο χρήστη** του — όνομα χρήστη και κωδικό.
   Ο σύνδεσμος «βήμα βήμα» δείχνει πώς τον φτιάχνετε.
4. **Τη διεύθυνση της σελίδας των εργαζομένων**: για να χτυπούν και από κινητά, διαλέξτε τη διεύθυνση του Wi-Fi του
   ιατρείου (π.χ. `192.168.1.20`). Αφήστε τη θύρα **8880**.
5. **Δοκιμαστικό ή πραγματικό μητρώο**. Το δοκιμαστικό σημαδεύει κάθε δήλωση «ΑΚΥΡΟ»· το πραγματικό ζητά ρητή επιβεβαίωση.
6. **Τον κωδικό του εργοδότη** (τουλάχιστον 10 χαρακτήρες): ανοίγει τις σελίδες του εργοδότη σε αυτόν τον υπολογιστή.
   Οι εργαζόμενοι δεν τον ξέρουν.

Μετά, με τον κωδικό του εργοδότη:

- **Προσωπικό** → νέος εργαζόμενος: το ΑΦΜ και το ονοματεπώνυμο **όπως στην ΕΡΓΑΝΗ**. Βγαίνει ένας **προσωρινός κωδικός**
  τεσσάρων ψηφίων — δώστε τον **αυτοπροσώπως**· στο πρώτο χτύπημα ο εργαζόμενος διαλέγει δικό του.
- **Συσκευές** → νέα συσκευή: ένας σύνδεσμος και ένα **QR**. Ανοίξτε τον μία φορά στον υπολογιστή της υποδοχής (και
  βάλτε τον στους σελιδοδείκτες), και σκανάρετέ τον με την κάμερα κάθε κινητού που θα χτυπά. Μόνο οι συσκευές της λίστας
  βλέπουν τη σελίδα.
- **Αντίγραφα** → ένα USB που μένει συνδεδεμένο, ή τον φάκελο του Dropbox. Αντίγραφο γίνεται κάθε μέρα μόνο του.
- **Αρχική** → «Έλεγχος σύνδεσης με την ΕΡΓΑΝΗ»: **μόνο ανάγνωση** — για κάθε παράρτημα, αν ο χρήστης του συνδέεται και
  αν του επιτρέπεται η δήλωση κάρτας. Τίποτα δεν δηλώνεται.

⛔ **Ο εργοδότης δεν χτυπά ποτέ κάρτα για τον εργαζόμενο** — δεν υπάρχει τέτοιο κουμπί. Ο κωδικός είναι του εργαζόμενου.

## 4. Κάθε μέρα

- **Ο εργαζόμενος:** στη σελίδα, το όνομά του → ο κωδικός του → **ΕΝΑΡΞΗ** ή **ΛΗΞΗ**. Η κάρτα φεύγει αμέσως για την
  ΕΡΓΑΝΗ· η σελίδα λέει όταν πέρασε.
- **Ο εργοδότης** (εικονίδιο «Κάρτα Εργασίας»): η Αρχική λέει αν κάτι θέλει απόφαση (μια κάρτα που δεν πέρασε στο 15λεπτο),
  αν ο υπολογιστής **δεν φτάνει την ΕΡΓΑΝΗ**, πότε έγινε το τελευταίο αντίγραφο, και αν υπάρχει νέα έκδοση.
- Αν η σελίδα δεν ανοίγει: **CardScanner**.

ⓘ Το πρόγραμμα ξεκινά όταν **συνδεθεί** ο χρήστης του υπολογιστή (όχι πριν). Ο υπολογιστής της υποδοχής ας συνδέεται
αυτόματα, ή ας συνδέεται κάποιος κάθε πρωί.

## 5. Ενημερώσεις

Μία φορά την ημέρα το πρόγραμμα ρωτά το GitHub αν υπάρχει νεότερη έκδοση — **τίποτα άλλο δεν στέλνεται, σε κανέναν**.
Η νέα έκδοση εγκαθίσταται **μόνη της τη νύχτα** (02:00–05:00), μόνο αν κανείς δεν έχει χτυπήσει την τελευταία ώρα και
καμία κάρτα δεν είναι καθ' οδόν. Εγκαθίστανται **μόνο** εκδόσεις υπογεγραμμένες με το κλειδί του έργου. Αν η νέα έκδοση
δεν ξεκινήσει σωστά, το πρόγραμμα **γυρίζει μόνο του** στην προηγούμενη, χωρίς να χαθεί τίποτα, και η Αρχική το λέει.

Στη σελίδα **Ενημερώσεις** του εργοδότη: η έκδοση, «Ενημέρωση τώρα», και ο διακόπτης για τη νύχτα. Αν ο υπολογιστής είναι
κλειστός τα βράδια, πατήστε «Ενημέρωση τώρα» όταν σας βολεύει (η σελίδα των εργαζομένων σταματά για ένα-δύο λεπτά).

## 6. Πού είναι το αρχείο — αντίγραφα και επαναφορά

Το αρχείο (κάρτες, προσωπικό, το μηνιαίο αρχείο της ΕΡΓΑΝΗ, ρυθμίσεις) είναι σε έναν φάκελο του χρήστη:

| Σύστημα | Φάκελος |
|---|---|
| Windows | `%LOCALAPPDATA%\Karta Ergasias` |
| Mac | `~/Library/Application Support/Karta Ergasias` |
| Linux | `~/.local/share/karta-ergasias` |

Περιέχει ΑΦΜ, ώρες εργασίας και τους κωδικούς των περιορισμένων χρηστών: **φυλάξτε τον — και τα αντίγραφά του — όπως το
ίδιο το αρχείο**. Επαναφορά από αντίγραφο: κλείστε το πρόγραμμα, και αντιγράψτε τα `stamp.sqlite` και `records.sqlite`
του αντιγράφου στους φακέλους `stamp` και `records` του παραπάνω φακέλου.

## 7. Αφαίρεση

- **Windows:** Ρυθμίσεις → Εφαρμογές → «Κάρτα Εργασίας» → Κατάργηση εγκατάστασης.
- **Mac:** σύρετε την «Κάρτα Εργασίας» από τις Εφαρμογές στον Κάδο, και κάντε επανεκκίνηση.
- **Linux:** `sudo apt remove karta-ergasias` (ή `sh uninstall.sh` για το `.tar.gz`).

⛔ **Το αρχείο δεν σβήνεται ποτέ από την αφαίρεση**: ο εργοδότης το κρατά **πέντε χρόνια**.

## Όρια που πρέπει να ξέρετε

- Η σελίδα των εργαζομένων μιλά **απλό HTTP** μέσα στο δίκτυο του ιατρείου. Γι' αυτό: μόνο στο Wi-Fi του ιατρείου με
  κωδικό, ποτέ σε δίκτυο επισκεπτών ή σε δημόσιο δίκτυο. Η ρύθμιση αρνείται δημόσια διεύθυνση.
- Ένα πρόγραμμα ανά υπολογιστή, για έναν εργοδότη. Παραρτήματα **σε άλλο κτίριο** δεν βλέπουν αυτόν τον υπολογιστή· για
  αυτά υπάρχει η εγκατάσταση με Docker και Tailscale ([INSTALL.md](INSTALL.md)).
- Τα κινητά χτυπούν μόνο όσο ο υπολογιστής είναι ανοιχτός και στο ίδιο δίκτυο.

## English, in short

One program for the practice's reception computer (Windows, Mac, Linux), from the project's
[Releases](../../../releases/latest). It is **not signed with a paid certificate**: on the first install only, Windows
shows «More info → Run anyway», and macOS needs System Settings → Privacy & Security → «Open Anyway» (move the app to
Applications first). The setup runs in the browser, in Greek. The program starts at sign-in, keeps its data in the user's
own folder (never removed by uninstalling — it is the employer's five-year record), backs up daily to a USB stick or the
Dropbox folder, and **updates itself at night with releases signed by the project's key only**, going back by itself if
a new version does not start. Nothing is sent anywhere except one daily question to GitHub for the newest release.
Staff on phones need the practice's own Wi-Fi (plain HTTP on the local network; never a guest network).
