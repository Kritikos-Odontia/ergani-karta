# Εγκατάσταση

<img src="../src/brand/odontia-mark.svg" width="20" height="20" alt=""> Φτιαγμένο από την [Odontia](https://odontia.ai)

Η εγκατάσταση για **έναν εργοδότη** — με όσα παραρτήματα έχει. Παίρνει περίπου μία ώρα, συν τον χρόνο για να
φτιάξετε τους περιορισμένους χρήστες στην ΕΡΓΑΝΗ.

> ⛔⛔ **Στο πραγματικό μητρώο, κάθε κάρτα είναι νόμιμη δήλωση για συγκεκριμένο πρόσωπο.** Διαβάστε πρώτα τους
> κανόνες ([RULES.md](RULES.md)) — είναι σύντομοι. Το λογισμικό διατίθεται χωρίς καμία εγγύηση (άδεια EUPL-1.2).

## Τι χρειάζεστε

- **Έναν υπολογιστή που μένει πάντα ανοιχτός**, με [Docker](https://docs.docker.com/engine/install/) και Docker
  Compose 2.24 ή νεότερο: ένα μικρό PC ή ένα NAS στο ιατρείο, ή έναν server. Linux συνιστάται. Θέλει περίπου 400 MB
  μνήμης και ελάχιστο δίσκο (λίγα MB τον χρόνο).
- **Οι υπολογιστές της υποδοχής να τον βλέπουν** σε μια **ιδιωτική** διεύθυνση:
  - στο **ίδιο τοπικό δίκτυο** του ιατρείου (π.χ. `192.168.1.20`) — το απλούστερο, για ένα ιατρείο σε ένα σημείο·
  - ή μέσω **Tailscale** (ιδιωτικό κρυπτογραφημένο δίκτυο, διευθύνσεις `100.x`) — για παραρτήματα σε άλλη πόλη, ή
    όταν το τοπικό δίκτυο το μοιράζονται κι άλλοι.
  ⛔ **Ποτέ στο διαδίκτυο.** Η σελίδα δείχνει ονόματα και δέχεται κωδικούς· η ρύθμιση αρνείται δημόσια διεύθυνση.
- **Για κάθε παράρτημα, έναν περιορισμένο χρήστη ΕΡΓΑΝΗ** ([ERGANI-USER.md](ERGANI-USER.md)). Ποτέ τους κύριους
  κωδικούς του εργοδότη.
- **Το CardScanner** (η δωρεάν εφαρμογή του Υπουργείου) εγκατεστημένο σε ένα κινητό του ιατρείου — ως εφεδρεία, για
  όταν η σελίδα δεν ανοίγει.

## 1. Το λογισμικό

Σε έναν φάκελο του υπολογιστή, π.χ. `/opt/ergani` (ιδιοκτήτης ο χρήστης που τρέχει το Docker):

```sh
git clone <η διεύθυνση αυτού του αποθετηρίου> /opt/ergani
cd /opt/ergani
docker compose build
```

## 2. Η πρώτη ρύθμιση

```sh
docker compose run --rm setup
```

Σας ρωτά, στα ελληνικά, και ελέγχει κάθε απάντηση: το όνομα του ιατρείου, τον ΑΦΜ του εργοδότη, τα παραρτήματα (η
έδρα είναι το `0`) και τον περιορισμένο χρήστη καθενός, τη διεύθυνση της σελίδας, και — αν θέλετε — ειδοποιήσεις στο
κινητό και παρακολούθηση. Γράφει τις ρυθμίσεις στο αρχείο `.env` αυτού του φακέλου, ορατό μόνο στον ιδιοκτήτη του.
⛔ Δεν στέλνει τίποτα πουθενά (τρέχει χωρίς δίκτυο). ⛔ Το `.env` περιέχει τους κωδικούς ΕΡΓΑΝΗ: δεν μπαίνει ποτέ σε
git, σε email ή σε μήνυμα.

> **Δοκιμαστικό ή πραγματικό;** Η ρύθμιση προτείνει το **δοκιμαστικό** περιβάλλον της ΕΡΓΑΝΗ (ό,τι δηλώνεται εκεί
> σημαδεύεται «ΑΚΥΡΟ»), αν έχετε πρόσβαση σε αυτό. Για να περάσετε μετά στο πραγματικό, κάντε την εγκατάσταση από την
> αρχή σε **νέο φάκελο** με **άλλο σύντομο όνομα**: κάθε αρχείο θυμάται σε ποιο περιβάλλον γράφτηκε και αρνείται το
> άλλο, ώστε δοκιμαστικές δηλώσεις να μη μπλεχτούν ποτέ με το πραγματικό αρχείο. Ο έλεγχος του βήματος 5 μόνο
> διαβάζει, οπότε γίνεται με ασφάλεια και στο πραγματικό.

## 3. Τα δύο αρχεία — μία φορά

```sh
docker compose run --rm stamp ergani admin init
docker compose run --rm archive ergani pull --init-store
```

Το πρώτο είναι το αρχείο των καρτών (προσωπικό, συσκευές, κάθε κάρτα και η απόδειξή της). Το δεύτερο, το μηνιαίο
αντίγραφο από την ΕΡΓΑΝΗ για την πενταετή υποχρέωση. Ζουν σε δύο Docker volumes με το όνομα του ιατρείου
(`ergani-<όνομα>_stamp`, `ergani-<όνομα>_records`). ⛔ **Δεν διαγράφονται ποτέ** — είναι το αρχείο που οφείλει ο
εργοδότης για πέντε χρόνια.

## 4. Εκκίνηση

```sh
docker compose up -d
docker compose ps          # το stamp πρέπει να γράφει «healthy» μέσα σε ένα λεπτό
docker compose logs stamp  # «starting — realm …» και «page on 0.0.0.0:8880»
```

Από εδώ και πέρα ξεκινούν μόνα τους μετά από κάθε επανεκκίνηση του υπολογιστή.

ⓘ Με διεύθυνση **Tailscale** (`100.x`): αν μετά από επανεκκίνηση του υπολογιστή η σελίδα δεν ανοίγει, το Docker
ξεκίνησε πριν ανέβει το Tailscale — `docker compose up -d` ξανά. Μόνιμα, σε Linux: η ρύθμιση
`net.ipv4.ip_nonlocal_bind=1` (στο `/etc/sysctl.d/`) αφήνει τη σελίδα να ξεκινά πριν από τη διεύθυνση.

## 5. Έλεγχος — ΜΟΝΟ ανάγνωση

```sh
docker compose exec stamp ergani check
```

Για κάθε παράρτημα: συνδέεται με τον χρήστη του, ελέγχει ότι του επιτρέπεται η «Δήλωση έναρξης/λήξης εργασίας», και
διαβάζει το ωράριο της ΕΡΓΑΝΗ για μια αντίστοιχη μέρα του προηγούμενου μήνα. ⓘ Δεν δηλώνει τίποτα.

## 6. Το προσωπικό

Για κάθε εργαζόμενο που χτυπά κάρτα, με το όνομα και τον ΑΦΜ **ακριβώς όπως στην ΕΡΓΑΝΗ**:

```sh
docker compose exec stamp ergani admin add --afm <ΑΦΜ> --surname <ΕΠΩΝΥΜΟ> --first-name <ΟΝΟΜΑ> --display "<όνομα στην οθόνη>"
```

Τυπώνει έναν **προσωρινό κωδικό** (4 ψηφία): δώστε τον στον εργαζόμενο **αυτοπροσώπως**. Οι οδοντίατροι εξαιρούνται
από την κάρτα: είτε δεν τους προσθέτετε, είτε — αν εμφανίζονται στο ωράριο της ΕΡΓΑΝΗ — με
`--exempt "οδοντίατρος"`, ώστε να είναι γραμμένο ότι η εξαίρεση είναι σκόπιμη. Ξανατρέξτε το `check`: δεν πρέπει να
βγάζει «NOT ON THE LIST».

## 7. Οι υπολογιστές της υποδοχής

Για κάθε υπολογιστή (και κάθε κινητό) που θα δείχνει τη σελίδα:

```sh
docker compose exec stamp ergani admin enroll --label "Υποδοχή"                # ένα παράρτημα
docker compose exec stamp ergani admin enroll --branch 1 --label "Υποδοχή"     # πολλά: ποιου παραρτήματος
```

Τυπώνει έναν σύνδεσμο `/enroll/…` που ισχύει **30 λεπτά, μία φορά**. Ανοίξτε τον **σε εκείνον τον υπολογιστή**, μετά
τη διεύθυνση της σελίδας, π.χ. `http://192.168.1.20:8880/enroll/…`. Η σελίδα εμφανίζεται· βάλτε τη διεύθυνση
`http://192.168.1.20:8880/` στα αγαπημένα (ή σε πλήρη οθόνη). Από οποιαδήποτε άλλη συσκευή, η σελίδα γράφει μόνο «δεν
είναι εγγεγραμμένη». Συσκευή που χάθηκε ή άλλαξε: `admin devices` και `admin revoke-device --id N`.

## 8. Ειδοποιήσεις στο κινητό του εργοδότη — προαιρετικό

Όταν μια κάρτα δεν περνά ή κάποιος ξέχασε να χτυπήσει, η σελίδα το δείχνει πάντα. Για να το μαθαίνει και ο εργοδότης
στο κινητό, χρειάζεται δικός σας ntfy server με κωδικούς: [NOTIFICATIONS.md](NOTIFICATIONS.md). Μετά:

```sh
docker compose exec stamp ergani admin push-test
```

⚠ «Sent» σημαίνει μόνο ότι ο server το δέχτηκε· η επιτυχία είναι να το δει ο εργοδότης στο κινητό.

## 9. Παρακολούθηση — προαιρετικό

Αν έχετε [Uptime Kuma](https://github.com/louislam/uptime-kuma) (ή κάτι που δέχεται `?status=up|down&msg=…`), φτιάξτε
δύο «Push» monitors και δώστε τις διευθύνσεις τους στη ρύθμιση (ή στο `.env`: `STAMP_HEARTBEAT_URL`,
`ARCHIVE_HEARTBEAT_URL`):
- **η σελίδα**: χτυπά κάθε λεπτό όσο η αποστολή προς την ΕΡΓΑΝΗ δουλεύει — heartbeat 180 δευτερόλεπτα·
- **το μηνιαίο αρχείο**: χτυπά μία φορά τη μέρα, «up» μόνο όταν κάθε μήνας είναι πλήρης — heartbeat 26 ώρες.
Η σιωπή του είναι ο συναγερμός.

## 10. Οι εργαζόμενοι διαλέγουν κωδικό — πριν από την πρώτη κάρτα

Στον υπολογιστή της υποδοχής, ο καθένας πατά το όνομά του, γράφει τον προσωρινό κωδικό, διαλέγει τον **δικό του**
(δύο φορές), και μετά πατά **Άκυρο** στην οθόνη ΕΝΑΡΞΗ/ΛΗΞΗ: ο κωδικός ορίστηκε, **τίποτα δεν δηλώθηκε**. Ο κωδικός
είναι ένας για όλα τα παραρτήματα. Δώστε στον καθένα το φύλλο [STAFF-SHEET.md](STAFF-SHEET.md), τυπωμένο. Ο
εργοδότης δεν μαθαίνει ποτέ τον κωδικό κανενός — γι' αυτό δεν μπορεί να χτυπήσει κάρτα για άλλον.

## 11. Η πρώτη πραγματική κάρτα

Όχι δοκιμή: μια **αληθινή** δήλωση για μια **πραγματική** προσέλευση.
- **Πριν**: βήματα 1–10· το `check` χωρίς ⛔· το CardScanner έτοιμο στο κινητό· ο εργοδότης διαθέσιμος τα πρώτα 30
  λεπτά της μέρας.
- **Η στιγμή**: ο πρώτος που φτάνει χτυπά **ΕΝΑΡΞΗ** στη σελίδα, τη στιγμή που φτάνει. Μέσα σε λίγα δευτερόλεπτα η
  οθόνη πρέπει να γράψει «Στάλθηκε στην ΕΡΓΑΝΗ ✓ — αριθμός πρωτοκόλλου …».
  - ✓ Ο εργοδότης βλέπει στην ΕΡΓΑΝΗ ότι η κάρτα είναι εκεί· `admin cards` τη δείχνει «filed». Από εκεί και πέρα
    όλοι χτυπούν στη σελίδα.
  - ✗ Αν όχι: η σελίδα το λέει (πορτοκαλί, κόκκινο στα 5 λεπτά) και ξαναδοκιμάζει μόνη της. **Μην** χτυπήσει ξανά,
    ούτε στο CardScanner. Αν ως το 14ο λεπτό δεν έχει περάσει, πηγαίνει στη λίστα «Τι κάνω;» για εκπρόθεσμη αποστολή
    με αιτία. Τίποτα δεν χάνεται.
- **Μετά**: η ΛΗΞΗ του ίδιου ανθρώπου το απόγευμα· και `admin queue` — η απόδειξη PDF πρέπει να έχει έρθει.

## Καθημερινά

Τα συνηθισμένα — αργίες, ξεχασμένος κωδικός, ένας εργαζόμενος που φεύγει, το αρχείο ενός εργαζόμενου που το ζητά —
είναι στο [ADMIN.md](ADMIN.md).

⚠ **Αν μια κάρτα δεν στάλθηκε μέσα σε 15 λεπτά** (κόκκινο «ΔΕΝ στάλθηκε»), εκτός από την αιτία στη σελίδα, ο
εργοδότης **ειδοποιεί αμέσως την Επιθεώρηση Εργασίας — όταν αρχίζει το πρόβλημα ΚΑΙ όταν τελειώνει**. Η αιτία που
διαλέγεται στη σελίδα δεν αντικαθιστά αυτά τα δύο μηνύματα.

## Ενημέρωση σε νεότερη έκδοση

Εκτός ωραρίου του ιατρείου:

```sh
cd /opt/ergani && git pull && docker compose build && docker compose up -d
```

Μια κάρτα που χτυπήθηκε τα δευτερόλεπτα της επανεκκίνησης δεν χάνεται: γράφεται πριν από κάθε αποστολή και στέλνεται
μόλις η υπηρεσία ξαναρχίσει. Τα αρχεία ανεβαίνουν μόνα τους σε νεότερη μορφή· ποτέ προς τα πίσω.

## Αντίγραφα ασφαλείας

Κρατήστε αντίγραφο κάθε βράδυ των δύο volumes (με το εργαλείο αντιγράφων που ήδη χρησιμοποιείτε, από το `/var/lib/docker/volumes/`). Κάθε αρχείο
είναι ένα αρχείο SQLite χωρίς `-wal` δίπλα του. Το αντίγραφο είναι ασφάλεια· το αρχείο είναι τα ίδια τα volumes.

## Αφαίρεση

```sh
docker compose down
```

Οι εργαζόμενοι επιστρέφουν στο CardScanner. ⛔ **Ποτέ `docker compose down -v`** και ποτέ διαγραφή των volumes: είναι το
αρχείο του εργοδότη για τα πέντε χρόνια.

## Νέο παράρτημα αργότερα

Με τα βήματα του [ADMIN.md](ADMIN.md) §«Νέο παράρτημα», με αυτή τη σειρά — όχι μόνο με αλλαγή του `.env`.

## Δεύτερος εργοδότης στον ίδιο υπολογιστή

Ένας δεύτερος φάκελος (π.χ. `/opt/ergani-allos`), με δική του ρύθμιση, δικό του σύντομο όνομα και **άλλη θύρα**. Τίποτα
δεν μοιράζεται: άλλοι χρήστες ΕΡΓΑΝΗ, άλλα αρχεία, άλλη σελίδα. ⓘ Αν τον τρέχετε για λογαριασμό άλλου εργοδότη,
επεξεργάζεστε δεδομένα του προσωπικού του (χρόνο εργασίας): ο ΓΚΠΔ θέλει γραπτή συμφωνία μαζί του (άρθρο 28).
