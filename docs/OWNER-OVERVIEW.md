# Η καθημερινή εικόνα του εργοδότη

Μετά τη σύνδεση με τον κωδικό του εργοδότη, η **Αρχική** δείχνει τι χρειάζεται την προσοχή σας, για όλα τα
παραρτήματα. Η ώρα επάνω στη σελίδα είναι ώρα Ελλάδας. Ανανεώστε τη σελίδα για νεότερη εικόνα.

| Ένδειξη | Τι σημαίνει και τι κάνετε |
|---|---|
| **Αποστολές καρτών** | Πόσες από τις σημερινές κάρτες χρειάζονται απόφαση, χωριστά από τις προηγούμενες ημέρες. Οι κάρτες που ακόμη ξαναστέλνονται φαίνονται ως αναμονή επιβεβαίωσης· αν υπήρξε σφάλμα, εμφανίζεται το μήνυμά του. Ανοίξτε τις **Εκκρεμότητες** για τις αποφάσεις. |
| **Αποδείξεις PDF** | Κάρτες που στάλθηκαν αλλά δεν έχει ληφθεί ακόμη η απόδειξή τους, ακόμη και αν η αναζήτηση μόλις άρχισε. Ο σύνδεσμος ανοίγει τη λίστα στις **Εκκρεμότητες**, με όνομα, παράρτημα και ώρα. Το πρόγραμμα ζητά ξανά το PDF αυτόματα, αρχικά συχνότερα και κατόπιν καθημερινά. Αν έχει σταματήσει η αναζήτηση λόγω ηλικίας, η λίστα το λέει: ενημερώστε τον λογιστή για το PDF που λείπει. |
| **Σύνδεση με την ΕΡΓΑΝΗ** | Αν ο υπολογιστής έχει παρατηρήσει διακοπή τουλάχιστον δέκα λεπτών. Αυτό ελέγχει μόνο αν απαντά η διεύθυνση της υπηρεσίας. Πατήστε **Ελέγξτε τη σύνδεση κάθε παραρτήματος** για τον χωριστό έλεγχο του χρήστη· τα περιορισμένα δικαιώματα επιβεβαιώνονται από τον εργοδότη στις ρυθμίσεις της ΕΡΓΑΝΗ ([ERGANI-USER.md](ERGANI-USER.md)). |
| **Αντίγραφο ασφαλείας** | Η τελευταία προσπάθεια και αν πέτυχε. Αποτυχία ή επιτυχημένο αντίγραφο παλαιότερο της μίας ημέρας χρειάζεται έλεγχο. Ο σύνδεσμος ανοίγει τα **Αντίγραφα**, για να ελέγξετε τον φάκελο, να συνδέσετε το USB αν χρειάζεται και να πάρετε αντίγραφο τώρα. |
| **Μηνιαίο αρχείο ΕΡΓΑΝΗ** | Η τελευταία πλήρης μηνιαία ανάγνωση ενός παραρτήματος και οι μήνες / τα παραρτήματα που δεν ολοκληρώθηκαν στην τελευταία ανάγνωση. Για αποτυχία ανάγνωσης, ελέγξτε τη σύνδεση από τον σύνδεσμο· το καθημερινό αρχείο ξαναδοκιμάζει αυτόματα. Αν δεν διαβάζεται το τοπικό αρχείο, ο σύνδεσμος οδηγεί στις οδηγίες αντιγράφων και επαναφοράς. |

Το «σήμερα» αφορά την ημέρα που **χτυπήθηκε** η κάρτα, στην Ελλάδα. Μια ΛΗΞΗ μετά τα μεσάνυχτα εμφανίζεται στη
σημερινή εικόνα ακόμη και όταν ανήκει στην προηγούμενη εργάσιμη ημέρα. Παλιές εκκρεμότητες μένουν ορατές μέχρι να
αντιμετωπιστούν.

Η Αρχική διαβάζει μόνο τις καταγραφές του υπολογιστή. Το άνοιγμα ή η ανανέωσή της δεν στέλνει κάρτα, δεν επιλέγει
αιτία εκπρόθεσμης δήλωσης, δεν ξεκινά έλεγχο σύνδεσης και δεν παίρνει αντίγραφο. Οι ενέργειες γίνονται στις αντίστοιχες
σελίδες, μετά τη σύνδεση του εργοδότη.

Μην ξαναχτυπήσετε μία ήδη καταγεγραμμένη κάρτα επειδή εκκρεμεί η επιβεβαίωση ή το PDF της. Το **CardScanner** είναι η
εφεδρεία όταν η σελίδα των εργαζομένων δεν μπορεί να πάρει καθόλου χτύπημα ([STAFF-SHEET.md](STAFF-SHEET.md)). Αν μια
κάρτα δεν σταλεί μέσα σε δεκαπέντε λεπτά, ο εργοδότης ειδοποιεί την Επιθεώρηση Εργασίας όταν αρχίζει το πρόβλημα και
όταν τελειώνει· η επιλογή αιτίας δεν αντικαθιστά αυτές τις ειδοποιήσεις.

**Όριο της τρέχουσας ένδειξης αρχείου:** μία πλήρης μηνιαία ανάγνωση αφορά έναν μήνα και ένα παράρτημα. Δεν αποδεικνύει
ότι ολοκληρώθηκε όλη η ημερήσια αρχειοθέτηση ή ότι γράφτηκαν όλες οι σελίδες σύγκρισης. Η οθόνη το δηλώνει ρητά
([KNOWN-LIMITS.md](KNOWN-LIMITS.md)).

## English

After owner sign-in, **Home** shows today's cards needing a decision, earlier unresolved cards, submissions still
retrying, missing proof PDFs, the connection monitor, the latest backup attempt and the monthly archive reads. Each
area links to the existing action page. Refresh for current information; dates use Athens time and the actual stamp
day, including an overnight exit whose working day is yesterday.

Opening Home only reads local records. It does not file cards, approve late submissions, call the connection check or
make a backup. A successful filing can still lack its proof PDF: the queue lists these cards while automatic retrieval
continues, and says when retrieval has stopped because the filing is too old. Never stamp again to obtain a receipt.

The connection monitor only detects an address that has not answered for ten minutes; it does not verify credentials
or restricted permissions. The current archive indicator proves individual branch/month reads, rather than an entire
daily archive run or its comparison-page writes. A backup more than one day old, a failed backup and an unreadable
archive each show a next action. See [KNOWN-LIMITS.md](KNOWN-LIMITS.md).
