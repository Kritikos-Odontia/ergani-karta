# Τεχνική εγκατάσταση — Docker

Για τεχνικό που συντηρεί τον υπολογιστή: Docker και Compose 2.24+, Git, ιδιωτική διεύθυνση που βλέπουν οι συσκευές. Συνιστάται Linux, περίπου 400 MB μνήμης. Για άλλο κτίριο χρησιμοποιήστε ιδιωτικό δίκτυο όπως Tailscale. Όχι προώθηση θύρας ή δημόσιο tunnel.

## Εγκατάσταση στην ίδια έκδοση με τον οδηγό

Από τον [πηγαίο κώδικα της έκδοσης](download.md), σε φάκελο π.χ. `/opt/ergani`, ετοιμάστε το πρόγραμμα με τις παρακάτω εντολές. Ο ιδιοκτήτης πληκτρολογεί ο ίδιος τους περιορισμένους κωδικούς στη ρύθμιση· δεν τους δίνει σε βοηθό ή σε συνομιλία.

```sh
docker compose build
docker compose run --rm setup
docker compose run --rm stamp ergani admin init
docker compose run --rm archive ergani pull --init-store
docker compose up -d
docker compose ps
```

Η ρύθμιση γράφει το `.env` με δικαιώματα μόνο για τον ιδιοκτήτη. Περιέχει κωδικούς: δεν το εκτυπώνετε, δεν το ανεβάζετε σε git ή μήνυμα. Οι κύριοι κωδικοί ΕΡΓΑΝΗ δεν δίνονται στο πρόγραμμα. Η έδρα είναι το παράρτημα `0`.

Τα δύο volumes `ergani-<όνομα>_stamp` και `ergani-<όνομα>_records` είναι το αρχείο. Μην τα διαγράψετε. Μην αναμείξετε δοκιμαστικό και πραγματικό μητρώο: διαφορετικό περιβάλλον σημαίνει χωριστή εγκατάσταση και αρχεία.

## Πριν αρχίσει το προσωπικό

Ακολουθήστε τα [βήματα πρόσβασης](access.md): χρήστης ανά παράρτημα, ρητός έλεγχος περιορισμών στην πύλη, προσωπικό, εγγραφή συσκευών, προσωπικά PIN. Η εντολή `docker compose exec stamp ergani check` διαβάζει μόνο· δεν είναι δοκιμαστική δήλωση ούτε απόδειξη όλων των δικαιωμάτων.

Εκτυπώστε την [καθημερινή χρήση](daily.md). Η πρώτη κάρτα είναι πραγματική προσέλευση. Για αναλυτικές εντολές και νέο παράρτημα δείτε τα [INSTALL.md](../../INSTALL.md) και [ADMIN.md](../../ADMIN.md). Νέο παράρτημα θέλει και εγγραφή στο αρχείο, πριν ξαναρχίσει η υπηρεσία.

Μετά από επανεκκίνηση με Tailscale, αν η σελίδα λείπει, περιμένετε να συνδεθεί το ιδιωτικό δίκτυο και ξανατρέξτε `docker compose up -d`.

Η καθημερινή ανάγνωση του μηνιαίου αρχείου τρέχει στις 03:15. Παρακολουθήστε `docker compose logs archive`. Ρυθμίστε [αντίγραφα](backups.md) εκτός του υπολογιστή.

Για διακοπή: `docker compose down`, **χωρίς `-v`**. Τα volumes μένουν.
