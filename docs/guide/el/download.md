# Λήψη, κώδικας, άδεια και ασφάλεια

> **Η Κάρτα Εργασίας είναι δωρεάν, χωρίς υποστήριξη και χωρίς εγγύηση (EUPL-1.2). Κάθε ιατρείο παραμένει υπεύθυνο για τις δικές του δηλώσεις στην ΕΡΓΑΝΗ.**

Κατεβάστε μόνο από την επίσημη σελίδα εκδόσεων του έργου. Ο σύνδεσμος της έκδοσης στη σελίδα του οδηγού αντιστοιχεί στην έκδοση που διαβάζετε· ελέγξτε ότι συμφωνεί με την εγκατεστημένη έκδοση.

| Σύστημα | Αρχείο εγκατάστασης |
|---|---|
| Windows 64-bit | `karta-ergasias-<έκδοση>-windows-x64-setup.exe` |
| Mac Apple | `karta-ergasias-<έκδοση>-mac-arm64.zip` |
| Mac Intel | `karta-ergasias-<έκδοση>-mac-x64.zip` |
| Ubuntu / Debian | `karta-ergasias-<έκδοση>-linux-x64.deb` |
| Άλλο Linux 64-bit | `karta-ergasias-<έκδοση>-linux-x64.tar.gz` |

Τα Windows και το Mac εμφανίζουν προειδοποίηση γιατί δεν υπάρχει πληρωμένο πιστοποιητικό υπογραφής. Ακολουθήστε τον αντίστοιχο οδηγό εγκατάστασης. Η έκδοση περιέχει `SHA256SUMS` και υπογραφή για τεχνικό έλεγχο· οι αυτόματες ενημερώσεις τα ελέγχουν με το κλειδί του έργου. Ο πρώτος εγκαταστάτης δεν επαληθεύεται αυτόματα για λογαριασμό σας.

## Ελεύθερος πηγαίος κώδικας

Ο κώδικας είναι στο [Kritikos-Odontia/ergani-karta](https://github.com/Kritikos-Odontia/ergani-karta). Οι σελίδες του οδηγού προέρχονται από τον φάκελο `docs/` της αναγραφόμενης πηγής. Η άδεια είναι η [EUPL-1.2](../../../LICENSE): διαβάστε το κείμενό της για τους όρους χρήσης και διανομής και την αποποίηση εγγύησης. Αναφορά συνεισφορών: [CONTRIBUTING.md](../../../CONTRIBUTING.md).

## Αναφορά ασφαλείας

Χρησιμοποιήστε το GitHub **Security → Report a vulnerability** του έργου, ιδιωτικά. Μην δημοσιεύσετε κενό ασφαλείας σε issue. Μην στείλετε πραγματικό ΑΦΜ, όνομα, login, κωδικό, πρωτόκολλο ή αντίγραφο αρχείου. Περιγράψτε το με κατασκευασμένα στοιχεία. **Μη δοκιμάσετε σε κανένα περιβάλλον ΕΡΓΑΝΗ** και μη στείλετε δήλωση ως απόδειξη· χρησιμοποιήστε το τοπικό fake του έργου. Πολιτική: [SECURITY.md](../../../SECURITY.md). Δεν υπάρχει αμοιβή αναφοράς.
