# Εγκατάσταση σε Linux

Χρειάζεστε Linux 64-bit. Για Ubuntu 22.04+, Debian 12+ και Mint, από τη [λήψη](download.md) επιλέξτε το `…-linux-x64.deb`.

- Διπλό κλικ → Εγκατάσταση, ή από τον φάκελο της λήψης:

```sh
sudo apt install ./karta-ergasias-<έκδοση>-linux-x64.deb
```

- Για άλλες διανομές, αποσυμπιέστε το `…-linux-x64.tar.gz` και μέσα στον αποσυμπιεσμένο φάκελο τρέξτε `sh install.sh` **ως ο χρήστης σας**, χωρίς sudo.

Ανοίξτε την **Κάρτα Εργασίας** από τις εφαρμογές. Η ρύθμιση ανοίγει στον browser (`http://127.0.0.1:8881`). Συνεχίστε με [χρήστες, PIN και συσκευές](access.md). Το πρόγραμμα ξεκινά στη σύνδεση του χρήστη μέσω systemd user service· ο υπολογιστής πρέπει να μένει ανοιχτός.

Αν χρησιμοποιείτε τείχος προστασίας, επιτρέψτε τη θύρα 8880 μόνο από το ιδιωτικό δίκτυο του ιατρείου. Μην την εκθέσετε στο διαδίκτυο. Για υπολογιστή χωρίς γραφικό περιβάλλον ή απομακρυσμένα παραρτήματα χρησιμοποιήστε τον [τεχνικό οδηγό Docker](docker.md).

Αφαίρεση εφαρμογής: `sudo apt remove karta-ergasias`, ή `sh uninstall.sh` για το tar.gz. Το αρχείο του εργοδότη μένει· μην το σβήσετε μαζί με το πρόγραμμα.
