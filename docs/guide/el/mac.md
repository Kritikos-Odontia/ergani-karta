# Εγκατάσταση σε Mac

Χρειάζεστε macOS 13.5 ή νεότερο. Στο μενού Apple → Πληροφορίες για αυτό το Mac δείτε αν γράφει Τσιπ Apple ή Επεξεργαστής Intel. Από τη [λήψη](download.md) διαλέξτε `…-mac-arm64.zip` για Apple ή `…-mac-x64.zip` για Intel.

1. Ανοίξτε το zip και σύρετε την **Κάρτα Εργασίας στις Εφαρμογές (Applications)**. Μην την τρέχετε από τις Λήψεις.
2. Ανοίξτε την από τις Εφαρμογές. Αν δεν μπορεί να επαληθευτεί ο δημιουργός, πατήστε **Τέλος**.

![Σχέδιο του μηνύματος ότι η εφαρμογή δεν ανοίχτηκε](../../images/mac-1-not-opened.svg)

3. Ρυθμίσεις συστήματος → **Απόρρητο και ασφάλεια** → στη γραμμή για την Κάρτα Εργασίας **Άνοιγμα ούτως ή άλλως**. Δώστε τον κωδικό του Mac και επιλέξτε Άνοιγμα.

![Σχέδιο του Open Anyway στις ρυθμίσεις ασφαλείας](../../images/mac-2-open-anyway.svg)

Οι εικόνες Mac είναι σχέδια των βημάτων. Το έργο δεν διαθέτει Apple Developer ID· οι ενημερώσεις ελέγχονται χωριστά με το κλειδί του έργου.

4. Ο browser ανοίγει τη ρύθμιση (`http://127.0.0.1:8881`). Συνεχίστε με [χρήστες, PIN και συσκευές](access.md).
5. Αν το τείχος προστασίας ρωτήσει για εισερχόμενες συνδέσεις του **node**, επιλέξτε να επιτρέπονται για να συνδέονται τα κινητά στο δίκτυο του ιατρείου.

Η εφαρμογή ξεκινά σε κάθε σύνδεση του χρήστη στο Mac. Μην αφήνετε τον υπολογιστή να κοιμάται όσο χτυπούν κάρτα οι εργαζόμενοι.
