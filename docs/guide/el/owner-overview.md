# Η καθημερινή εικόνα του εργοδότη

Στον υπολογιστή εγκατάστασης ανοίξτε την **Αρχική** και συνδεθείτε με τον κωδικό εργοδότη. Βλέπετε όλα τα παραρτήματα μαζί. Ανανεώστε τη σελίδα για νεότερη εικόνα· οι ώρες είναι Ελλάδας.

| Ένδειξη | Τι ελέγχετε |
|---|---|
| **Αποστολές καρτών** | Τις σημερινές κάρτες που χρειάζονται απόφαση, χωριστά από τις παλιότερες. Η αναμονή επιβεβαίωσης διαφέρει από την αποτυχία. Ανοίξτε **Εκκρεμότητες** για την απόφαση. |
| **Αποδείξεις PDF** | Κάρτες που επιβεβαιώθηκαν αλλά ακόμη δεν έχουν PDF. Η λίστα δείχνει όνομα, παράρτημα και ώρα. Δεν ξαναχτυπάτε κάρτα. |
| **Σύνδεση ΕΡΓΑΝΗ** | Διακοπή απάντησης τουλάχιστον δέκα λεπτών. Ανοίξτε τον χωριστό [έλεγχο σύνδεσης](connection-check.md) για κάθε χρήστη. Η ένδειξη δεν ελέγχει δικαιώματα. |
| **Αντίγραφο ασφαλείας** | Την τελευταία προσπάθεια και αν πέτυχε. Αποτυχία ή επιτυχία παλιότερη της μίας ημέρας θέλει έλεγχο στη σελίδα **Αντίγραφα**. |
| **Μηνιαίο αρχείο ΕΡΓΑΝΗ** | Τον τελευταίο επιτυχημένο ημερήσιο έλεγχο, τη νεότερη αποτυχία, τους ελλιπείς μήνες/παραρτήματα, προειδοποιήσεις μηδενικών κινήσεων και σελίδες σύγκρισης που δεν γράφτηκαν. Επιτυχία παλιότερη των 36 ωρών επισημαίνεται. |

Το «σήμερα» αφορά την ημέρα που χτυπήθηκε η κάρτα στην Ελλάδα. Μια ΛΗΞΗ μετά τα μεσάνυχτα εμφανίζεται σήμερα ακόμη κι αν η εργάσιμη ημέρα της είναι χθες. Οι παλιές εκκρεμότητες παραμένουν ορατές.

## Τι αποδεικνύει η εικόνα του αρχείου

Η Αρχική διαβάζει αποθηκευμένα τοπικά στοιχεία. Η ώρα επιτυχίας του αρχείου αφορά τον **ημερήσιο έλεγχο**, που μπορεί να χρησιμοποιεί πλήρεις αναγνώσεις έως επτά ημερών. Δεν σημαίνει ότι ξαναδιαβάστηκε κάθε κίνηση εκείνη τη στιγμή. Μέχρι να υπάρξει ημερήσια κατάσταση, μια χωριστά σημειωμένη πλήρης ανάγνωση αφορά μόνο έναν μήνα/παράρτημα.

Νεότερη αποτυχία δεν κρύβει την τελευταία επιτυχία. Μήνες που χάθηκαν από το διαθέσιμο διάστημα της ΕΡΓΑΝΗ μένουν στη λίστα, παρότι δεν μπορούν πια να ανακτηθούν από εκεί. Αποτυχία δημιουργίας σελίδας σύγκρισης μπορεί να υπάρχει μαζί με πλήρεις αποθηκευμένες εγγραφές. Αν το τοπικό αρχείο δεν διαβάζεται, ακολουθήστε τις [οδηγίες επαναφοράς](new-computer.md).

## Τι κάνετε μετά

Το άνοιγμα της Αρχικής δεν στέλνει κάρτα, δεν επιλέγει αιτία και δεν παίρνει αντίγραφο. Ακολουθήστε τον σύνδεσμο της ένδειξης. Η λήψη PDF ξαναδοκιμάζεται αυτόματα· η λίστα λέει όταν η αναζήτηση έχει σταματήσει λόγω ηλικίας (όριο 183 ημερών). Ενημερώστε τότε τον λογιστή.

Μόλις ένα πρόβλημα εμποδίσει την αποστολή, ειδοποιήστε ΑΜΕΣΑ την Επιθεώρηση Εργασίας και ΞΑΝΑ μόλις τελειώσει, ακόμη κι αν οι επόμενες προσπάθειες στείλουν όλες τις κάρτες μέσα σε δεκαπέντε λεπτά. Η επιλογή αιτίας εκπρόθεσμης δήλωσης δεν αντικαθιστά τις δύο ειδοποιήσεις.

Μην επαναλάβετε ήδη καταγεγραμμένη κάρτα επειδή εκκρεμεί απάντηση ή PDF. [CardScanner](daily.md) χρησιμοποιείται όταν η σελίδα δεν μπορεί να καταγράψει κάρτα. Για αποστολή που δεν πρόλαβε, δείτε [αποτυχίες και λογιστή](failures.md). Αναλυτική αναφορά: [OWNER-OVERVIEW.md](../../OWNER-OVERVIEW.md).
