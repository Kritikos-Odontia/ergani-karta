# Download, source, licence and security

> **Work Card is free, without support and without warranty (EUPL-1.2). Each practice remains responsible for its own ΕΡΓΑΝΗ filings.**

Download only from the project's official release page. The version link on the guide page matches the version you are reading; check it against your installed version.

| System | Installer file |
|---|---|
| Windows 64-bit | `karta-ergasias-<version>-windows-x64-setup.exe` |
| Mac Apple silicon | `karta-ergasias-<version>-mac-arm64.zip` |
| Mac Intel | `karta-ergasias-<version>-mac-x64.zip` |
| Ubuntu / Debian | `karta-ergasias-<version>-linux-x64.deb` |
| Other 64-bit Linux | `karta-ergasias-<version>-linux-x64.tar.gz` |

Windows and Mac warn because there is no paid code-signing certificate. Follow the relevant installation chapter. The release carries `SHA256SUMS` and its signature for technical verification; automatic updates check them against the project's key. The first downloaded installer is not automatically verified for you.

## Security reporting

Use the project's GitHub **Security → Report a vulnerability**, privately. Do not publish a security flaw in an issue. Do not send real tax identifiers, names, logins, passwords, protocol numbers or a record backup. Demonstrate it with fabricated data. **Do not test against any ΕΡΓΑΝΗ environment** or file a declaration as proof; use the project's local fake. Policy: [SECURITY.md](../../../SECURITY.md). There is no bug bounty.
