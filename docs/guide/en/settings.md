# Settings and branches

On the computer running the program open **Ρυθμίσεις (Settings)** with the owner password. These changes do not stamp a card or change the ministry register.

## ΕΡΓΑΝΗ connection

For the correct branch select **Αλλαγή σύνδεσης ΕΡΓΑΝΗ**, enter the new restricted username and the new password twice. The old password is not shown. Settings retain the program's existing private local-file protection.

Saving runs a read-only check. It confirms sign-in and an offered card form, not filing permission or correct restrictions. Follow the [separate portal check and human confirmation](connection-check.md). Failed new credentials remain saved; correct them on the same page. Do not substitute master credentials.

## Owner password and names

To change the owner password, enter the old password and the new one twice, at least 10 characters. All existing owner sessions close; sign in again. Five wrong old passwords block further change attempts for ten minutes.

**Older backups still need the password used when they were made.** Keep it in your password manager with the backup date.

Correcting a practice or employee name adds a new fact rather than rewriting an old card. Older cards, including pending ones, retain their captured name. A tax identifier cannot change. If the ministry register is wrong, contact the accountant.

## Branches

- **Add:** use its existing ministry number (head office `0`), a label and its own restricted login. Choose whether its standing schedule is read. After the connection check it also appears in Calendar. Enrol its reception device under **Συσκευές (Devices)**. Adding it here does not register a branch with the ministry.
- **Rename:** changes the displayed label and records that correction. The number and older cards remain.
- **Retire:** only once work there has stopped. New cards stop, including on enrolled devices. History, login, pending submissions, receipts and monthly reads remain. This does not delete or close the branch at ΕΡΓΑΝΗ. There is no reactivation screen.

Changing the connection, practice name or branches briefly restarts the staff page after the current send finishes. An archive read already running finishes with its original connection; the next uses the new one. Do not remove an older branch's login from settings.
